# 洋楽カラオケ (Karaoke) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 曲名から LRCLIB の時刻つき歌詞と YouTube の動画を探し、歌詞を見ながら歌った録音を Gemini が採点して、発音できなかった単語を出すモード「Karaoke」を作る。

**Architecture:** シャドーイングとは別のモード。純粋な部分 (歌詞の読み込み・ずらし・切り方・採点の読み方・JSON) を小さなクラスに分けてロジックテストで固め、
画面と流れ (KaraokeScreen / KaraokeSession) はそれを組み合わせるだけにする。Answer と同じく、実行時に画面と隠れたタブを作り Modes のカードにする (シーンは変えない)。

**Tech Stack:** Unity 2022.3 (uGUI + TextMeshPro, C#), Gemini REST (responseSchema), LRCLIB (`https://lrclib.net/api/search`), YouTube Data API, Supabase (Postgres RPC + RLS), 素の JS の Web。

**Spec:** `docs/superpowers/specs/2026-11-10-karaoke-design.md`

## Review Focus

1. 時刻つきの歌詞が無い曲 (plainLyrics だけ) → 候補に出さない。全部無ければ「No lyrics for this song. Try another title.」 (Task 2 のテスト)
2. ライブ版・リミックスなど長さの違う歌詞 → 動画の長さに一番近い歌詞を選ぶ (Task 2 のテスト `PickBest`)
3. 数秒で Stop → 歌った行が 2 行未満なら採点しない「Please sing a little more.」 (Task 1 のテスト `SungLines`)
4. 間奏の空行 (`[01:02.00]` だけ) → 表示の行には入れるが、採点・点数の単語数には数えない (Task 1・3 のテスト)
5. Gemini が歌詞に無い単語や範囲外の行番号を返す → 捨てる (Task 3 のテスト)

### Task 1: LrcLyrics (歌詞の読み込み・ずらし・今の行・切り方)

**Files:**
- Create: `Assets/Script/CorrectionDiary/Karaoke/LrcLyrics.cs`
- Test: `Tests~/LogicTests/KaraokeTests.cs` (新規。`Program.cs` の Main に `KaraokeTests();` を足す)

**Interfaces:**
- Produces:
  - `public class LrcLine { public double Time; public string Text; public bool IsBlank => string.IsNullOrWhiteSpace(Text); }`
  - `public static class LrcLyrics`
    - `List<LrcLine> Parse(string lrc)` — `[mm:ss.xx]`・`[mm:ss]`・1 行に複数の時刻 (同じ文を時刻ごとに) に対応。`[ar:..]` などのタグと壊れた行は捨てる。時刻順。
    - `double AutoOffset(int videoSeconds, double lyricsSeconds)` — 差の絶対値 ≤ 3 なら 0、それ以外は `videoSeconds - lyricsSeconds` (正なら歌詞を遅らせる)。
    - `int IndexAt(IList<LrcLine> lines, double videoTime, double offset)` — `Time + offset <= videoTime` の最後の行。まだなら -1。
    - `List<LrcLine> SungLines(IList<LrcLine> lines, double stoppedAt, double offset)` — 始まりが stoppedAt より前の空でない行。
    - `List<(double start, double end, List<int> lines)> Chunks(IList<LrcLine> lines, double offset, double recordStart, double recordEnd, int maxSeconds = 180)` — 録音の秒 (動画の時刻 − recordStart) で、行の境目だけで切る。空行は含めない。

- [ ] **Step 1: テストを書く** (`KaraokeTests.cs`)

```csharp
var lines = LrcLyrics.Parse("[ar:Someone]\n[00:12.50]Hello world\n[00:15.00][01:15.00]Chorus line\n[00:20.00]\nbroken\n[00:18]No hundredths");
Check(lines.Count == 5, "lrc: 5 lines (tag and broken dropped)");
Check(lines[0].Time == 12.5 && lines[0].Text == "Hello world", "lrc: first line");
Check(lines[2].Time == 18 && lines[3].IsBlank && lines[4].Time == 75 && lines[4].Text == "Chorus line", "lrc: sorted, blank kept, repeated time");
Check(LrcLyrics.AutoOffset(200, 198.5) == 0 && LrcLyrics.AutoOffset(215, 200) == 15, "lrc: offset within 3s is 0, else intro");
Check(LrcLyrics.IndexAt(lines, 12.0, 0) == -1 && LrcLyrics.IndexAt(lines, 16, 0) == 1 && LrcLyrics.IndexAt(lines, 16, 2) == 0, "lrc: line at time with offset");
// 1 番だけ歌って止めた: それより後の行は入らない
Check(LrcLyrics.SungLines(lines, 16, 0).All(l => l.Time < 16), "lrc: stop early -> only sung lines");
Check(LrcLyrics.SungLines(lines, 16, 0).Count == 2 && LrcLyrics.SungLines(lines, 100, 0).Count == 4, "lrc: sung lines skip blanks");
// 4 分の歌詞を 0〜240 秒録音 → 180 秒を超えない・行の境目で切る
var long4 = LrcLyrics.Parse(string.Join("\n", Enumerable.Range(0, 24).Select(i => $"[{i * 10 / 60:00}:{i * 10 % 60:00}.00]line {i}")));
var chunks = LrcLyrics.Chunks(long4, 0, 0, 240);
Check(chunks.Count == 2 && chunks.All(c => c.end - c.start <= 180) && chunks[0].end == chunks[1].start, "lrc: chunks <= 180s on line borders");
Check(chunks.SelectMany(c => c.lines).Count() == 24, "lrc: every line in one chunk");
```

**Files:**

    プロンプト: 「歌っている録音。伴奏は無い (イヤホン)。歌詞の各行で、発音できていない・歌えていない単語と、原因の音 (コード: SoundTypes.All のどれか、なければ other) を返す。リズムや音程は見ない。advice は日本語で 2〜3 文」。

  - `static KaraokeCheck GeminiApiClient.ParseKaraokeCheck(string json, IList<(int index, string text)> lines)` — 範囲外の行番号・その行に無い単語 (大文字小文字・前後の記号を無視) は捨てる。知らない音は `"other"`。
  - `public static class KaraokeScorer`
    - `int Score(IList<LrcLine> sung, IEnumerable<KaraokeLineResult> results)` — `100 * (歌った行の単語数 − 赤い単語数) / 歌った行の単語数` を四捨五入。単語数 0 なら 0。
    - `List<SoundHit> Sounds(IEnumerable<KaraokeLineResult> results)` — 赤い単語ごとに `{Code = sound, Word = word}` (最大 20)。
    - `string Highlight(string text, IEnumerable<KaraokeMiss> missed, string color)` — 赤い単語を `<color=..>` で囲む。

- [ ] **Step 1: テストを書く**

```csharp
var ls = new List<(int, string)> { (0, "I want it that way"), (1, "Tell me why") };
var check = GeminiApiClient.ParseKaraokeCheck("{\"lines\":[{\"line\":0,\"missed\":[{\"word\":\"That\",\"sound\":\"th\"},{\"word\":\"banana\",\"sound\":\"r_l\"}]}," +
    "{\"line\":7,\"missed\":[{\"word\":\"why\",\"sound\":\"w\"}]}],\"advice\":\"thを意識\"}", ls);
Check(check.Lines.Count == 1 && check.Lines[0].Missed.Single().Word == "that", "karaoke: drop unknown words and lines");
Check(check.Advice == "thを意識", "karaoke: advice");
var sung = LrcLyrics.Parse("[00:01.00]I want it that way\n[00:05.00]\n[00:06.00]Tell me why");
Check(KaraokeScorer.Score(sung.Where(l => !l.IsBlank).ToList(), check.Lines) == 88, "karaoke: score 7/8 words");
Check(KaraokeScorer.Highlight("I want it that way", check.Lines[0].Missed, "#f00") == "I want it <color=#f00>that</color> way", "karaoke: highlight");
Check(GeminiApiClient.ParseKaraokeCheck("not json", ls).Lines.Count == 0, "karaoke: bad json");
```

(音のコードは `SoundTypes.All` にあるものを使う。`th` / `r_l` が無い名前なら、テストの値を `SoundTypes.All` の実際のコードに合わせる。)

# 機能まとめ (Voice English Corrector)

2026-11-09 時点。話した英語を文字起こし・添削し、いろいろな形で練習できる Unity 製の英語学習アプリ (Android)。
詳しい使い方は `README.md`、内部の仕組みは `docs/TECHNICAL.md`、各機能の設計は `docs/superpowers/specs/` を参照。

## 1. Practice: 英語の添削
- 録音 → 文字起こし → 添削。端末内蔵の音声認識を使い (Android / iOS)、使えない環境では録音した WAV を Gemini で文字起こし
- 添削エンジンを切り替え
  - **Gemini**: 文法の修正と、なぜ直したかの解説
  - **DeepL Write**: より自然な言い換え

## 2. Diary: 英語日記
- 停止ボタンまで話し続けられる (音声認識が切れても自動で再開)。終わったら日記全体を添削
- **連続記録 (ストリーク)**: 日記を書いた日数と今週の達成状況
- **ログイン・クラウド保存** (任意): Supabase。Web 版と共通
- **Discord 連携** (任意): 添削した日記を送信。直した単語に下線
- **リマインダー** (任意): 夜までに書いていなければ Discord に通知 (Cloudflare Worker)
- 直した単語は緑の太字で表示

## 3. Summary: 動画の要約練習
- YouTube Data API で字幕付きの短い英語動画 (40 秒〜2 分半) をランダムに出題。アプリ内の埋め込みプレーヤーで再生
- 動画のあと制限時間 (標準 60 秒) で話して要約
- Gemini が動画そのものを見て採点: 内容 50 + 構成 25 + 文法・語彙 25
- 押さえた点・抜けた点・文法の指摘・お手本・改善例も表示
- 結果は Discord (専用チャンネル) とクラウドへ。Web で推移をグラフ表示
- ログアウト中の結果は、ログイン後にアップロード

## 4. Topic: お題スピーキング
- お題 (Exam / Daily / Work) を Gemini が毎回作る。通信できなければアプリ内のリストから
- 流れ: お題 → 考える時間 (標準 60 秒、スキップ可) → 話す (45〜60 秒) → 採点 → 言い直し
- 録音を Gemini に直接渡して、文字起こしと採点を 1 リクエストで行う
- 採点: 内容 40 + 構成 30 + 言葉 30。添削・言い換え・次に使える表現・苦手チェック
- **言い直し (Read aloud)**: 直された文を読み、単語ごとに緑 / 赤と一致率 % を表示。`Pronunciation check` で発音コメント
- 別の画面で採点が終わると、タブの点と Android のトーストで知らせる
- **よくあるミスの集計**: 日記・要約・お題の添削から 10 種類 (冠詞・時制・前置詞・主語と動詞の一致・単複・動詞の形・語順・単語選び・抜けた語・その他) に分類。Web で苦手を表示し、話す前の「今日の注意」と採点の重点チェックに使う

## 5. Repeat: リピーティングとシャドーイング
### リピーティング
- 1 回 5 文。英文は見せずに読み上げ → 言い返す。言えた単語は緑・抜けた単語は赤、一致率 % を表示
- 文の出どころ: 前回 80% 未満の文 → 自分の添削文 → [Tatoeba](https://tatoeba.org/) の文 (データは git に入れない)
- 声: Tatoeba は本物の人の録音、自分の文は Gemini の音声合成 (Leda)。失敗時は端末の読み上げ
- `Again` / `Slow` (0.75 倍。声の高さは変わらない)。録音は端末に保存 (最大 300 個・60 MB)
- 結果はクラウド (Web で推移と苦手な文)・Discord
### シャドーイング (`Shadowing: On`)
- 動画のタイトルで YouTube を検索して選ぶ。初めての動画だけ Gemini がお手本の文字起こしを作る (端末に最大 20 本)
- 動画の再生と同時に録音 → 3 分ずつ Gemini で書き起こし → お手本と照合
- 平均・文ごとの色分け・日本語アドバイス (発音・リズム・遅れ)・`My voice`
- イヤホンの確認つき。クラウドと Web には点数だけ。音声は保存しない

## 6. 苦手な発音と「今日の発音練習」
- お題の `Pronunciation check` で、問題の音 (`Sound: TH` など。固定 10 種類 + その他) を表示
- 言い直しとリピーティングで言えなかった単語のつづりからも苦手な音を数える
- Web の「よくあるミス」ページで 7 / 30 / 90 日の集計を表示
- 1 日の最初の練習のあと、苦手 1 位の音のネイティブ練習動画を YouTube で探し、発音用の Discord チャンネルに 1 日 1 回送る (同じ動画は 30 日送らない)

## 7. Vocab: 単語帳
- **Today / Words / Settings** (Add タブは 11/3 にやめた)
- **Today**
  - 初回にレベル (A1〜B2) を選ぶ。1 回分は 5 / 10 / 15 / 20 語
  - 出る順: 学習中 → 期限が来た復習 → 新しい単語 ([CEFR-J](https://github.com/openlanguageprofiles/olp-en-cefrj) の自分のレベルから、辞書で引けたもの)。期限切れの復習が 50 語を超えたら新しい単語は出さない
  - カード: 表 = 単語・レベル・発音記号・`Sound`・`Say it` / 裏 = 品詞ごとの意味とレベル・自分の意味・例文
  - 評価 4 段階 (`Didn't know` / `Hard` / `Knew it` / `Easy`)。次の復習日は **FSRS-4.5** (目標の想起率 90%、設定で 80〜95%)
  - 発音チェック: 端末の音声認識でその場で `Clear` / `Close` / `Try again`、録音して回の終わりに **Gemini** がまとめて採点 (最大 20 語を 1 リクエスト)
  - まとめ: `My voice` / `Model`、`Score again`、`Practice weak words`、`Level up to ...?` の提案
  - 1 回終えた日は連続記録に数える (Web のカレンダーは紫)
- **Words**: 学習中 / わかった の切り替え、レベルで絞り込み、`Back to learning` / `Delete`
- **Settings**: レベル・語数・目標の想起率・出典の表示
- 辞書は Merriam-Webster's Learner's Dictionary (音声・派生語の音声にも対応)。保存は端末の中 (`persistentDataPath/vocab/`) で、クラウドには「やった日」だけ
- Vocab 画面は Unity のメニュー **Tools → Vocabulary → Create / Update Vocabulary Screen** で組み立てる

## 8. Talk: 3D キャラクターとの英会話 (実験中)
- VRM キャラクターと音声で会話。LLM は LLMUnity でスマホの中で動かす
- 返事は 1 文ずつ読み上げ、口パク・うなずきつき
- 返事の感情に合わせて表情が変わる。Android のみ対応

## 共通の仕組み
- **ログイン・保存**: Supabase (日記・結果・ミス・苦手な音・連続記録)。Web 版 (`database_learnApp`) と共通
- **Gemini の API キーを画面ごとに分ける**: 日記 / 要約 / お題 / 読み上げ / シャドーイング / 単語帳。上限 (429) になったら他のキーを借りる
- **連続記録のカレンダーの色**: 日記=オレンジ、要約=青、お題=緑、単語帳=紫、2 種類=銅/銀、3 種類以上=金 (Web)
- **画面の組み立てツール** (`Assets/Editor/`): Summary / Topic / Repeat / Vocabulary / Login の各 Builder。iOS ビルド後の設定は `IosPostBuild.cs`
- **データの扱い**: Tatoeba のデータ・CEFR-J の元 CSV・API キーは git に入れない。録音・お手本は端末の中だけ
- **テスト**: `Tests~/LogicTests/` (FSRS・辞書の解析・出題順・採点など)、Python 側 (`Tools~/tatoeba`, `Tools~/cefrj`)
